MATERIA DÉBIL

1. Ejecuta supabase_migration_materia_debil.sql en Supabase SQL Editor.
2. Despliega este proyecto normalmente en Render.
3. La tarjeta “TU MATERIA DÉBIL” aparece en la pantalla principal después de iniciar sesión.
4. El sistema empieza a acumular estadísticas por materia desde los nuevos exámenes realizados después de esta actualización.
5. La materia débil es la de menor porcentaje entre las materias con respuestas registradas.
6. “ENTRENAR MATERIA” genera hasta 20 preguntas exclusivamente de esa materia.
